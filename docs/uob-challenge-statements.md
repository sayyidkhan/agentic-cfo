# UOB Challenge Statements — Reference Transcription

Source: UOB challenge screenshot shared during planning. Original PNG is retained in the local documentation bundle; adding binary media to GitHub requires a separate binary-capable commit operation.

## 1. AI-Powered Financial Assistance and Service Support
**Challenge:** How might we use AI to help individuals and families access financial information, assistance schemes, and banking-related support more easily and confidently?

**What participants can explore:**
- AI-powered assistants that answer common financial questions in simple language.
- Tools that help users navigate financial literacy resources or assistance programmes.
- Solutions that reduce time spent searching for information and improve user experience.

## 2. Smarter Access to Banking and Financial Opportunities
**Challenge:** How might we use AI to help individuals better discover, understand, and access financial products, services, and opportunities that suit their needs?

**What participants can explore:**
- AI tools that recommend suitable savings, budgeting, or financing options.
- Solutions that simplify financial decision-making for students, young adults, or underserved communities.
- Platforms that help users understand eligibility requirements and next steps.

## 3. Proactive Financial Wellbeing and Engagement
**Challenge:** How might we use AI to help individuals develop healthier financial habits by identifying needs early and providing timely, personalized guidance?

**What participants can explore:**
- AI solutions that encourage budgeting, saving, or responsible spending habits.
- Tools that provide personalized financial tips based on user behaviour and goals.
- Ideas that help individuals take action before financial challenges become more serious.

## Agentic CFO alignment
**Primary fit: Theme 3.** Track budgets and net worth to provide early, personalised guidance for working professionals. Custom databases and autonomous payments are intentionally outside the POC.
